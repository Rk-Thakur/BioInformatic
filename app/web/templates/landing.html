{# ---------------------------------------------------------------- problem #}
The problem

One gene can decide the whole treatment

Monogenic diabetes is caused by a change in a single gene. It makes up about 1–2% of diabetes, yet around 80% of cases are misdiagnosed as type 1 or type 2. The right diagnosis changes daily care:

GCK

Usually no medication

Mild, stable blood sugar. Treatment can often be stopped outside pregnancy.

HNF1A · HNF4A

Low-dose sulfonylurea tablets

Often works better than insulin, so a patient may move from injections to tablets.

KCNJ11 · ABCC8

High-dose sulfonylurea

Neonatal diabetes from an activating variant can be treated with tablets instead of insulin.

{# ---------------------------------------------------------------- hidden risk #}
The hidden risk

Genetic knowledge keeps changing, but test results are read once

Many variants are first reported as uncertain (VUS). As evidence grows, ClinVar reclassifies them. Most record systems check a result only once, so an upgrade never reaches the doctor, and a patient can stay on insulin when tablets would work.

{# ---------------------------------------------------------------- how #}
How it works

Four steps, repeated every time knowledge changes

  1. 1{{ icon('upload') }}

    Store

    The lab uploads the patient's VCF. Variants in the 7 diabetes genes are kept with the patient's diagnosis and current medicines.

  2. 2{{ icon('book') }}

    Classify

    Each variant is looked up in a versioned ClinVar release. ClinGen expert-panel classifications take priority.

  3. 3{{ icon('pill') }}

    Advise

    Six treatment rules compare the gene result with current therapy, e.g. "HNF1A + insulin: consider low-dose sulfonylurea".

  4. 4{{ icon('refresh') }}

    Re-check

    When a new ClinVar release or rule arrives, only patients whose variants changed are re-evaluated, and the doctor is notified.

Upgradenew high-priority alert, marked reclassified
Downgradeold alert superseded + review notice, never a silent change
Small changehistory updated quietly, no notification
